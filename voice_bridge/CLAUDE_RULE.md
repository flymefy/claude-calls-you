## Voice call to the user (voice-call MCP)
- You have a `call_user` tool that phones the user. Follow the `phone-call-user` skill for when and how to use it.
- Short version: call only before an irreversible action, when fully blocked on a decision, or after a long task; write the message in the user's language, first person, 2-3 short sentences; never more than two calls for the same question; on no clear answer, never assume consent: write the question in chat and hold the sensitive action.
